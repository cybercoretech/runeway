# Runeway

A retro side-scrolling view of your running coding agents, in the terminal. Each agent gets its own lane and an original pixel-art runner that shows what it is doing, how many tokens it has used, and when it is waiting for you. Runeway only reads agent-deck's session list and the agents' own transcripts; it never writes to them and never touches the network.

Phase 1 (in progress): the data sources, `runeway status [--json]`, `runeway check` and a live list view.
